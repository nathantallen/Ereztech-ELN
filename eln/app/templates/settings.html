File format

Everything is stored as plain, human-readable files — the notebook remains fully legible without this application:

data/
├─ users.json                  accounts & roles
├─ properties.json             physical-properties DB (self-learning)
├─ equipment.json              Home Assistant + hood assignments
├─ notebook/
│  └─ ELN-2026-0001/
│     ├─ entry.md              YAML header (reaction, stoichiometry,
│     │                        equipment, run times) + Markdown sections
│     ├─ observations.md       timestamped actions and observations
│     ├─ audit.log             append-only event history
│     ├─ structures/           .mol (+ rendered .svg)
│     ├─ sensors/              one CSV per logged sensor
│     ├─ photos/  recordings/  camera captures during the run
│     └─ attachments/          videos, sensor logs, spectra…
└─ materials/
   └─ trimethylgallium/
      ├─ material.md
      ├─ batches/tmg-2606-a.md
      └─ attachments/          certificates of analysis

Because records are plain text, the share can be indexed, backed up, diffed and read directly from SharePoint or the NAS.
